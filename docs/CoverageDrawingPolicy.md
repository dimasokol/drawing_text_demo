# CoverageDrawingPolicy

Используется определения и правила, перечисленные в [DrawingPolicy.md](./DrawingPolicy.md).

Рисование в `CoverageDrawingPolicy` устроено по следующим принципам.

# Принципы

Если текст короткий, и влезает в ширину целиком, то результат измерения остаётся таким же, как
в `DefaultDrawingPolicy`.

Код должен манипулировать шириной рисования (в пределах области рисования), стараясь нарисовать
текст с максимальным покрытием текстом той области, которую занимает измеренный результат. Иначе 
говоря, из всех результатов измерения должен быть выбран тот, ограничивающие прямоугольники строк
в котором занимают максимальную долю площади прямоугольника, ограничивающего весь результат.

Важно: долю НЕ всей доступной области, а именно от результата измерения на каждой итерации.

Шаг проверки размера должен составлять 1sp.

При подборе ширины рисования не стоит уменьшать её более чем до 0.6 от ширины области. Если высота
результата превысила область рисования, то дальнейший подбор прекращается.
