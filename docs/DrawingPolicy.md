# Назначение

Эти правила относятся к политикам рисования текста: реализациям 
`ru.dimasokol.demo.drawingtext.policies.TextDrawingPolicy`.

Реализации должны располагаться в `ru.dimasokol.demo.drawingtext.policies`.

# Словарь

* **Область** (**область рисования**) — максимально доступная для рисования область, ширина и высота
  которой переданы при первом вызове `measure`
